# 🎨 Random Background Color Changer

A simple and interactive web application that changes the background color of a container every time a button is clicked, using a predefined array of vibrant colors.

## 🔗 Live Demo
👉 [https://your-color-picker.ccbp.tech](https://mgrandomcolorg.ccbp.tech)

## 🚀 Features
- **Dynamic Color Switching:** Changes the background color instantly upon clicking the button.
- **Randomized Logic:** Uses a JavaScript array and random index generation to ensure variety.
- **Responsive Layout:** Built with Bootstrap's grid system to work seamlessly on mobile and desktop.
- **Smooth UI:** Features a clean interface with custom Google Fonts and styled components.

## 🛠 Technologies Used
- **HTML5:** For the structural layout.
- **CSS3:** For custom styling, height management, and button design.
- **Bootstrap 4.5:** For responsive columns and utility classes.
- **JavaScript (ES6):** For array manipulation, math functions, and DOM style updates.

## 📚 What I Learned
- **Array Iteration:** Accessing elements from a list using random indices.
- **Math.random() & Math.floor():** Generating valid integer indices based on the array length.
- **DOM Styling:** Dynamically updating the `style.backgroundColor` property of an element.
- **Responsive Design:** Using Bootstrap classes like `col-md-6` and `d-flex` for alignment.

## 🕹️ How to Use
1. Open the application in your browser.
2. Click the **"Click Me"** button on the left (or top on mobile).
3. Watch the right-hand panel (or bottom panel) change to a new random color from the palette.
