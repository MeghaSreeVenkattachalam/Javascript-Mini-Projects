# 🐶 Puppy Like and Unlike App

An interactive JavaScript application that allows users to like and unlike a puppy image. The image and button styles change dynamically when the user clicks the Like button.

## 🔗 Live Demo
👉 https://toggleunlike.ccbp.tech

## 🚀 Features
- Toggle like and unlike functionality
- Dynamically change image when liked
- Change icon color on click
- Update button background and text color
- Simple and responsive layout

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- Font Awesome (CDN)

## 📚 What I Learned
- DOM manipulation using getElementById
- Handling toggle logic using boolean variables
- Dynamically updating image source
- Changing styles using JavaScript
- Using external CDN libraries properly
