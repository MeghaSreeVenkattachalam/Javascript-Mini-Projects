# 🌦️ Seasons Switcher App

An interactive JavaScript application that allows users to switch between different seasons (Spring, Summer, Autumn, Winter) by clicking buttons, dynamically updating the displayed images.

## 🔗 Live Demo
👉 https://mseasonswitcher.ccbp.tech

## 🚀 Features
- Switch between Spring, Summer, Autumn, and Winter
- Dynamically updates images based on selected season
- Responsive images for small and medium devices
- Clean and simple user interface

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## 📚 What I Learned
- DOM manipulation using getElementById
- Updating image `src` dynamically with JavaScript
- Handling multiple button click events
- Responsive design using Bootstrap display classes
