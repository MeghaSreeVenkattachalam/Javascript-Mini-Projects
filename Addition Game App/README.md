# ➕ Addition Game App

An interactive web-based arithmetic game that challenges users to calculate the sum of two randomly generated numbers.

## 🔗 Live Demo
👉 [https://megadditionapp.ccbp.tech](https://megadditionapp.ccbp.tech)

## 🚀 Features
- **Dynamic Number Generation:** Automatically generates two random integers between 1 and 100 using JavaScript.
- **Real-time Validation:** Instantly checks the user's answer against the correct sum.
- **Visual Feedback:** - **Success:** Displays "Congratulations!" with a green background.
  - **Error:** Displays "Please Try Again!" with a blue background.
- **Restart Functionality:** Reset the game and generate new numbers without refreshing the page.

## 🛠 Technologies Used
- **HTML5:** Page structure and Bootstrap integration.
- **CSS3:** Custom styling with Google Fonts (Roboto).
- **Bootstrap 4.5:** Responsive layout and button styling.
- **JavaScript (ES6):** Core logic, DOM manipulation, and event handling.

## 📚 What I Learned
- **Math Functions:** Using `Math.random()` and `Math.ceil()` to generate random integers.
- **DOM Manipulation:** Accessing and updating elements using `document.getElementById()`.
- **Event Handling:** Triggering logic through `onclick` attributes.
- **Type Conversion:** Using `parseInt()` to handle user input for mathematical comparisons.

## 🕹️ How to Play
1. Observe the two numbers shown on the screen.
2. Calculate the sum of the numbers.
3. Enter your answer in the input field.
4. Click the **Check** button to see if you are correct.
5. Click **Restart** to generate a new pair of numbers and try again.
