# 🛠️ Button Maker

An interactive web tool that allows users to design and customize a button in real-time by manipulating various CSS properties through input fields.

## 🔗 Live Demo
👉 [https://your-button-maker.ccbp.tech](https://mgbuttonmaker.ccbp.tech)

## 🚀 Features
- **Real-time Customization:** Change background color, font color, size, weight, padding, and border radius.
- **Dynamic Styling:** Updates the "Custom Button" live when the Apply button is clicked.
- **Responsive Interface:** Uses Bootstrap’s grid system to provide a side-by-side layout for inputs and the preview.
- **Elegant Design:** Features a modern linear-gradient background and clean UI components.

## 🛠 Technologies Used
- **HTML5:** For creating the input forms and preview area.
- **CSS3:** For the gradient background, custom fonts (Roboto), and layout styling.
- **Bootstrap 4.5:** For responsive columns (`col-md-7`, `col-md-5`) and utility styling.
- **JavaScript (ES6):** For capturing user input and dynamically applying styles to the DOM.

## 📚 What I Learned
- **DOM Style Manipulation:** Using `element.style.property` to update CSS values dynamically via JavaScript.
- **Input Handling:** Retrieving values from various text inputs to use as CSS property values.
- **Unit Management:** Understanding how to pass strings (like "20px" or "bold") from inputs directly into style objects.
- **Layout Alignment:** Using Bootstrap's flexbox and spacing utilities to center and organize content.

## 🕹️ How to Use
1. Enter a color name or hex code in the **Background Color** and **Font Color** fields.
2. Provide numeric values (e.g., "20px") for **Font Size**, **Padding**, and **Border Radius**.
3. Specify a **Font Weight** (e.g., "bold" or "500").
4. Click the **Apply** button to see your custom design reflected on the button to the right!
