# 🖼️ Image Size Adjuster App

An interactive JavaScript application that allows users to increase or decrease the width of an image using plus and minus buttons.

## 🔗 Live Demo
👉 https://imgsizeadjuster.ccbp.tech

## 🚀 Features
- Increase image width by 5px on each click
- Decrease image width by 5px on each click
- Displays current image width dynamically
- Shows warning messages when size exceeds limits
- Responsive layout using Bootstrap

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

- Dynamically updating element styles
- Handling increment and decrement logic
- Setting boundary conditions (min & max limits)
- Updating text content dynamically
