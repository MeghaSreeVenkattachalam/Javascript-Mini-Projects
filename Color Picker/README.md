# 🎨 Color Picker App

An interactive JavaScript application that allows users to change the background color by clicking on different color buttons.

## 🔗 Live Demo
👉 https://megcolorpicker.ccbp.tech

## 🚀 Features
- Change background color dynamically
- Display selected color hex code
- Clean and responsive UI

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## 📚 What I Learned
- DOM manipulation
- Handling click events
- Updating styles dynamically
- Updating text content using JavaScript
