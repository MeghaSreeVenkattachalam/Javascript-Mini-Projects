# 💡 Light Switch App

A simple interactive JavaScript project that simulates a light switch.

## 🔗 Live Demo
👉 https://lighttoggleapp.ccbp.tech

## 🚀 Features
- Switch light ON and OFF
- Dynamic image updates
- Button color changes based on state
- Real-time DOM manipulation

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## 📚 What I Learned
- DOM manipulation using `getElementById`
- Changing image source dynamically
- Updating text content
- Styling elements dynamically using JavaScript
