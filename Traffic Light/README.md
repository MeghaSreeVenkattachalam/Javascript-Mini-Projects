# 🚦 Traffic Light App

An interactive JavaScript application that simulates a traffic light system where users can control the lights using Stop, Ready, and Go buttons.

## 🔗 Live Demo
👉 https://megtrafficlight.ccbp.tech

## 🚀 Features
- Turn on Red light using Stop button
- Turn on Yellow light using Ready button
- Turn on Green light using Go button
- Automatically reset other lights when one is active
- Simple and responsive UI design

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## 📚 What I Learned
- DOM manipulation using getElementById
- Handling multiple button click events
- Dynamically changing CSS styles with JavaScript
- Organizing HTML, CSS, and JS into separate files
