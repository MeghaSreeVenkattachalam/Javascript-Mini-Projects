# 💰 Tip Calculator App

An interactive JavaScript application that calculates the tip amount and total bill based on the bill amount and tip percentage entered by the user.

## 🔗 Live Demo
👉 https://megtipcalci.ccbp.tech

## 🚀 Features
- Calculate tip amount based on entered percentage
- Automatically calculate total bill amount
- Displays error messages for invalid or empty inputs
- Responsive layout using Bootstrap
- Clean and user-friendly interface

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap

## 📚 What I Learned
- DOM manipulation using getElementById
- Handling user input and form validation
- Using parseFloat() to convert string to number
- Performing mathematical calculations dynamically
- Displaying formatted numbers using toFixed()
