# 🎯 Number Guessing Game

An interactive JavaScript game where users try to guess a randomly generated number between 1 and 100.

## 🔗 Live Demo
👉 https://megguessinggame.ccbp.tech

## 🚀 Features
- Random number generation
- User input validation
- Dynamic feedback (Too High / Too Low)
- Background color changes based on result

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## 📚 What I Learned
- Using Math.random()
- Conditional statements
- DOM manipulation
- Handling user input
